# I Don't Care

**Simple Mod** that adds a "Don't show again" checkbox to world backup and experimental confirmation popups with seamless vanilla styling, per-world persistence, and Mod Menu configuration.

---

## Features
- **Vanilla Look & Feel**: Uses pure vanilla `CheckboxWidget` and UI components matching Minecraft's native style.
- **Per-World Persistence**: Checking "Don't show again" remembers your choice specifically for that world in `.minecraft/config/idontcare.json`.
- **Edit World Integration**: Easily re-enable or toggle the backup prompt anytime by visiting **Edit World** and checking/unchecking the option.
- **Mod Menu Support**: Includes a lightweight, zero-dependency configuration screen accessible from Mod Menu.
- **Customizable Actions**: Choose whether bypassing warnings should load directly or automatically generate a backup in the background.
- **Subtle Toast Feedback**: Optional toast notifications when a warning is automatically bypassed.
